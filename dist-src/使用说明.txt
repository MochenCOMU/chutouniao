=================================================
【它解决什么问题】

很多软件会强制绑死某个操作，还不给你改：

  · Photoshop —— 按住 Ctrl 就切成移动工具，一拖图层就跑；Ctrl+Alt 拖拽还会复制出一堆图层
  · 文件资源管理器 —— Ctrl+拖拽会变成「复制文件」
  · Maya —— Alt+左/中/右键 = 旋转/平移/缩放，改不掉
  · 3ds Max —— Shift+拖拽 = 克隆
  · 还有各种「按错就触发、关又关不掉」的固定快捷键

这些行为大多写死在程序里，选项里没有、键盘快捷键对话框里也改不动。
「出头鸟」不去改它们，而是在 Windows 的输入层先把这条输入接住：

  鼠标：按住某些修饰键再拖 → 整个拖拽失效
  键盘：按下某个组合 → 在这个程序里等于没按；
        也可以「转发」成另一个组合，功能还在，只是换了个键。

=================================================
【怎么用】

1. 装好后桌面右下角（托盘）会出现一个小盾牌，那就是它在工作，没有主窗口。
2. 打开 Photoshop，按住 Ctrl 在画布上拖 —— 什么都不会发生。
3. 双击托盘图标 = 打开设置；右键 = 暂停/恢复、打开配置文件夹、退出。
4. 开始菜单里有「出头鸟 Chutouniao」，卸载去「设置 > 应用」，或者运行安装目录里的 Uninstall.exe。

=================================================
【设置界面有三个页】

◆ 程序与规则
  左边是它管哪些程序（进程名，不含 .exe）。
  · 「添加程序…」从正在运行的程序里挑
  · 「添加预设」直接套用现成方案（Photoshop / 资源管理器 / Maya / 3ds Max / Figma）
  · 选中程序后，右边配它自己的规则：
      - 鼠标拖拽：勾修饰键（Ctrl/Alt/Shift/Win）+ 选左/中/右键 → 添加
      - 键盘快捷键：点一下输入框，按组合键 → 添加
        · 不勾「转发为」= 这个组合在该程序里彻底失效
        · 勾了「转发为」再按新组合 = 原组合被拦下，改发新组合
    规则只对选中的程序生效，不同软件互不干扰。

◆ 细节
  · 小位移算作点击：把被吞掉的单击补发出去，保住 Ctrl+单击 这类操作
  · 判定阈值：多少像素以内算「点击」而不是「拖拽」
  · 拦截时播放提示音 / 闪烁托盘图标
  · 「最近一次拦截」：显示刚才拦了什么，用来确认它真的在工作

◆ 通用
  · 开机自动启动
  · 暂停 / 恢复快捷键 —— 自己按什么就是什么（默认 Ctrl+Alt+Shift+F12）
  · 导入配置 / 导出配置：把配好的方案发给别人，或带到另一台机器

=================================================
【快捷键转发：禁用不等于功能没了】

有些软件的快捷键又蠢又不让改，直接禁掉又发现那个功能再也调不出来，
所以键盘规则可以「转发」：

    原组合：Ctrl+Shift+E        新组合：Alt+E

以后按 Ctrl+Shift+E，程序收到的是 Alt+E —— 等于给这个改不掉的功能换了键。

实现上做了两件事，所以基本能对上：
  · 手上多按着、但新组合不需要的修饰键，会先替你在程序那边「松开」，发完再「按回去」；
  · 新组合需要、但你手上没按的修饰键，会临时补上再撤掉。
所以 Ctrl+Alt+M → Ctrl+M 这种「减一个键」的改法也能正确生效。

限制：
  · 一次只转发成一个组合键，不支持发一串宏。
  · 转发目标带 Win 的组合可能触发系统自己的快捷键（比如 Win+E 打开资源管理器）。
  · 只对键盘生效；鼠标拖拽只能拦，不能改成别的动作。

=================================================
【几条要记住的规则】

· 规则是「精确匹配」。勾了 Ctrl+左键拖拽，那么按住 Ctrl+Shift 拖拽就不会被拦 ——
  多按一个键就是临时放行，这也是给自己留的后路。
· 键盘规则同样精确匹配：配了 Ctrl+Shift+E，Ctrl+E 照样能用。
· 没有修饰键的规则（裸拖拽 / 单键）也能加，但那会让这个操作在该程序里彻底失效，
  添加时会让你再确认一次。

=================================================
【已知代价（如实说明）】

· 勾了 Ctrl+左键拖拽之后，Photoshop 自由变换里的「Ctrl 拖角=扭曲」也会被挡，
  因为它同样是 Ctrl+拖拽。要用时走 编辑 > 变换 > 扭曲，或者先按暂停快捷键。
· 如果目标程序是「以管理员身份运行」的，本工具受 Windows 权限隔离，拦不住。
· 它只能拦住「输入」这一步：程序里对应的图标可能还会闪一下，但不会真的执行。

=================================================
【配置文件 / 便携模式 / 导入导出】

%APPDATA%\Chutouniao\settings.ini，纯 INI 文本，可以直接用记事本改，下次启动生效。
如果 exe 旁边放一个 settings.ini，程序就进入便携模式，配置跟着文件夹走。

=================================================
【卸载】

设置 > 应用 > 出头鸟 Chutouniao > 卸载；或者运行安装目录里的 Uninstall.exe。
它会删掉程序、开始菜单快捷方式、开机启动项和配置，不留垃圾。

【技术说明】

用 WH_MOUSE_LL + WH_KEYBOARD_LL 两个全局钩子实现，不需要驱动、不需要管理员权限。
如果杀毒软件误报（钩子类程序偶尔会），加个信任即可。
源码在 GitHub 上，用 Windows 自带的 .NET Framework 编译器就能编译，不需要 Visual Studio。
